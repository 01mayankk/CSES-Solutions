Creating Strings

Task

Given a string, your task is to generate all different strings that can be created using its characters.

Input

The only input line contains a string of length n.
Each character is a lowercase English letter ('a'–'z').

Output

First print an integer k: the number of distinct strings.
Then print the k strings in alphabetical (lexicographical) order.

Constraints

1 ≤ n ≤ 8

Example

Input
aabac

Output
20
